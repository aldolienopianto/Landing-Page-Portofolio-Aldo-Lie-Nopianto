# Aldo Lie Nopianto — Personal Portfolio

Source code for **[aldolienopianto.com](https://aldolienopianto.com)**, a personal portfolio landing page highlighting work across **strategy, design, and engineering**. 

Built with a focus on clean typography, responsive layout, and real-time interactive particle simulations.

## ✨ Key Features

- **Interactive Particle Simulations:** Real-time background visualizers featuring 4 distinct modes:
  - `01` **Nebula**
  - `02` **Torus**
  - `03` **Lattice**
  - `04` **Vortex**
- **Dynamic Color Themes:** Instant theme switcher to toggle accent color palettes seamlessly.
- **Minimalist & Modern UI:** High-contrast dark mode interface designed for clarity and impact.
- **Responsive Design:** Optimized for smooth performance across desktop and mobile viewports.

## 🛠️ Tech Stack

- **Core:** HTML5, CSS3, JavaScript (ES6+)
- **Graphics & Animation:** HTML5 Canvas API
- **Hosting & Deployment:** GitHub Pages / Netlify
